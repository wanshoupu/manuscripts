\chapter{Power of sentinels} \label{ch:sentinels}

Sentinels are added for multiple reasons.
- Get rid of `Loop-and-a-half'.
- Avoid costly condition-checking on performance-critical inner loops.

Sentinels shifts certain condition-checking from within a loop to post-loop processing.
The computation saving is huge if the condition-checking is costly and the loop size is big.

To get the concept of sentinels, Wikipedia has quite a good introduction that readers are
encouraged to get familiar with
\footnote{\url{https://en.wikipedia.org/wiki/Sentinel_value}}.

But at the root, sentinels are added to make the problem more symmetric so as to promote
coding uniformity.
I first came to learn about sentinels and their usage in the book ``Numerical Receipt in C''
~\cite{NumericalRecipes:1992} in the section ``Quicksort''.
I was really amazed by the use of sentinels on ends of the array so that
the inner loop doesn't need to check for array boundaries when partitioning the array elements
by the pivot element.

Later on in my own software development practice, I made conscious choice when facing similar
problems.
