\chapter{Loops} \label{ch:loops}

All major programming languages features one or more loop as a type of control flow.
You can visualize a loop construct as a carousel or a Ferris wheel, with an
entrance, a number of turns and an exit.
Loop is a powerhouse, a productivity amplifier for programing-with a static loop body,
one or a few loop variable(s), and nominal overhead code, the loop may be executed as many
times as needed.

To developers, much of the coding work is spent on choosing the right loop construct, choosing
loop variable(s), and designing the loop body.

Construction wise, loop is like an embedded machine inside computer programs-one prepares
input, feed it to the loop, and collect the output at the end.

\code{for}-loop and \code{while}-loop are the most common looping flow of control that almost all
languages support.
\code{do-while}-loop is a variation of \code{while}-loop that's supported by \java, \cpp, C, and
others but not \python.

``Why!'', you say, ``What makes you talking about loops as a language feature without a
language context?''
As in in \fullref{ch:organizeYourIfElse}, I want to share some of my coding experience which
address many beginner's problems and most importantly may be an inspiration to other enterprising
programmers.

\section{Loop anatomy}\label{sec:loopAnatomy}
Although there are some variations, the basic constructs of a loop are the same.
\autoref{tbl:loop-construct} describes the coding parts of a loop.

\begin{table}[h]
    \begin{center}
        \caption{Function anatomy\label{tbl:loop-construct}}
        \begin{tabular}{l|p{10cm}}
            \hline
            construct & description \\
            \hline
            Pre-loop initialization &
            This is the preparation section in \code{for}-loop where variables declared there are
            usually hidden from subsequent code\footnote{This is is true for \java, \cpp, C,
            \textit{etc.}, but is not true for, \textit{e.g.}, bash}.
            Note that \code{while}-loop does not have a similar construct. \\
            Continuation condition &
            The condition for control to enter (or continue) the loop. \\
            Body &
            The block of statements to be executed in the loop. \\
            \code{break} statement &
            A statement in the loop body that breaks the loop and pass control to the next statement
            following the loop. \\
            \code{continue} statement &
            A statement in the loop body that interrupt the execution of the remaining statements in the loop.
            Note that this doesn't break the loop or pass control out of the loop. \\
            Post-loop processing &
            This is a rare construct in loop, supported by languages such as \python as
            \code{while-else} and \code{for-else}. \\
            \hline
        \end{tabular}
    \end{center}
\end{table}

Depending on the situation, a loop may or may not have certain parts as mentioned above.

I like for-loop for the limited scope of its loop-variables.
But I like to start with \code{while ( true )} or \code{for (; ; )}.
Once I get to the bottom of the algorithm, I will have a better idea as to what is the best
construct for the current problem.


\section{For-loop}

\begin{lstlisting}
    for(<init> ; <pre-stmt> ; <post-stmt> )
\end{lstlisting}
Think of \code{<pre-stmt>} as the first statement of each iteration of for-body.
Think of \code{<post-stmt>} as the last statement of each iteration of for-body.

\section{Precondition loop, midcondition loop, and postcondition loop}

How to choose the right loop for concise code?
\begin{itemize}
    \item Firstly use a generic (infinite loop) with break statements as exit points
    \item in the body such as for(;;) or while(true). After the structural
    \item statements are clear, one can choose a suitable, concise loop statements
\end{itemize}

What are the important parts when using a for-loop?
Questions to ask and answer
\begin{itemize}
    \item
    what's the initialization?
    Initialization is the starting points. To iterate over an array, for example,
    should the initialization be i = -1 or i = 0?
    \item
    when and where increment/decrement should happen?
    in the 3rd part of the for statement? or in the body?
    It's more flexible (sometimes necessary when certain condition has to be met to increment/decrement)
    if the increment/decrement is in the body. But it's more concise to put in the for-statement
    \item
    What's the termination condition and How many termination points?
    Often, infinite loop is resulted when incorrect assumption is made about the termination condition
\end{itemize}

1. Pre-condition loop
\begin{lstlisting}
    while (condition) {
        statements;
    }
\end{lstlisting}
and
\begin{lstlisting}
    for ( ; condition; ) {
        statements;
    }
\end{lstlisting}

2. Mid-condition loop

\begin{lstlisting}
    while (true) {
        statements;
        if (!condition) break;
        statements;
    }
\end{lstlisting}

3. Post-condition loop

\begin{lstlisting}
    do {
        statements;
    } while (condition);
\end{lstlisting}
