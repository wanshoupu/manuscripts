\chapter{Loop Thinning} \label{ch:loop-thinning}

Programming loops is a complex work.
First working version is seldom the best solution.
This chapter is a spinoff of the ~\autoref{ch:loops}.
We spend this chapter for the sole purpose of simplifying nested loops.
The rule of thumb is ``try to avoid nested loops'.
If nested loops can be simplified to one-layer loop, by using auxiliary data structures and so on,
that will be the first choice.
Otherwise,  refactoring the code may be necessary to decouple subtasks from the main one.

\section{Conclusion}

Nested loops are hard to understand and are generally considered unacceptable in production code.
They should be avoided if at all possible.
With the `loop thinning' technique discussed in this chapter, many cases of nested loops can be
compactify and converted to simple loop.
If this is not possible or the resulting code is even harder to understand, one should consider
refactor nested loop into smaller functions.
