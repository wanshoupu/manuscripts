\section{\ilcode{if-else}-condition}
(Evernte:if-else-if-else vs. continue in a loop)
The following two side-by-side code sections are equivalent.
But each has their own problem.
The left column do redundant condition testing (condition1), whereas the right column harepeated
code (statement2).

Let's think of the logic in terms of a real-world example.
Suppose you need to check schedule and weather before making a plan.
\begin{itemize}
    \item Condition C1: schedule permits
    \item Condition C2: weather permits
\end{itemize}

\begin{itemize}
    \item Action A1: Meet a friend
    \item Action A2: Have a walk
    \item Action A3: Call a friend
\end{itemize}

The conditions for action A1 is \code{C1 == True && C2 == True};
The conditions for action A2 is \code{C1 == True};
The conditions for action A3 is \code{C1 == False && C2 == False}.
