\chapter{Organize your \ilcode{if-elif-else} statements}
\section{\ilcode{if-else}-condition}
(Evernte:if-else-if-else vs. continue in a loop)
The following two side-by-side code sections are equivalent. But each has their own problem.
The left column do redundant condition testing (condition1), whereas the right column has repeated code (statement2).

The simplification of both lies in the smart use of continue:
\begin{lstlisting}

    while(condition_overall){
    if( !condition1 ){
    statement3
    continue;
    }
    //assert condition1
    if( condition2 ){
    statement1
    }
    statement2
    }
\end{lstlisting}
